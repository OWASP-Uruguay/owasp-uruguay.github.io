En esta meetup se usó el proyecto OWASP [Secure Coding Dojo](https://owasp.org/www-project-secure-coding-dojo/) para introducir a los participantes en la revisión de código y la detección de vulnerabilidades, mediante desafíos guiados y con el apoyo de expertos en seguridad de aplicaciones. Se realizó en [Switch Software Solutions](https://goo.gl/maps/mgiwWTx5Lqn5A17p9).

Como parte de la preparación, el capítulo colaboró con el proyecto: tradujo la presentación al español y la compartió con la comunidad.
