En esta jornada de colaboración se agregó a la versión Java del proyecto AntiSamy la validación por XSD de los XML de reglas. [Sebastián Passaro](https://uy.linkedin.com/in/sebastian-passaro) (OWASP Uruguay) había agregado esa validación a la versión .NET cuando retomó el proyecto y le hizo varias mejoras.
