Meetup virtual sobre los requerimientos de seguridad y el uso de los estándares que forman parte de los proyectos de documentación Flagship de OWASP.

Para aplicaciones web se presentó el Application Security Verification Standard (ASVS) y para aplicaciones móviles el Mobile Application Security Verification Standard (MASVS). Para probar esos requerimientos se presentaron las guías de testing: la Web Security Testing Guide (WSTG) y la Mobile Security Testing Guide (MSTG).
